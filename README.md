## English

A minimalist, modern, and secure note-taking app for iOS.

### Features

- **Face ID Security** — Biometric authentication on app launch
- **Folder System** — Organize your notes into folders
- **Category Support** — Tag your notes with color-coded categories
- **Copy & Paste** — Full support for select all, copy, and paste
- **Search** — Quickly search through your notes
- **Pin Notes** — Pin important notes to the top
- **Swipe Actions** — Quick delete and pin with swipe gestures
- **No Ads** — Completely free with no advertisements

### Tech Stack

| | |
|---|---|
| **Platform** | iOS 17.0+ (iPhone only) |
| **Language** | Swift + SwiftUI |
| **Storage** | SwiftData |
| **Architecture** | MVVM |
| **Security** | LocalAuthentication (Face ID / Touch ID) |

### Design

Minimalist modern design with a soft light blue (#A8D8EA) and sea green (#7EC8C8) color palette. Enhanced user experience with SF Symbols icons and smooth animations.

### Getting Started

1. Clone this repository
```bash
git clone https://github.com/fclk1212/FCNotes.git
```
2. Open `FCNotes.xcodeproj` in Xcode
3. Select your development team in Signing & Capabilities
4. Run on iPhone 15 Pro simulator or a physical device
