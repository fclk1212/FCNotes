# FCNotes

Minimalist, modern ve güvenli bir iOS not uygulaması.

## Özellikler

- **Face ID Güvenliği** — Uygulama açılışında biyometrik kimlik doğrulama
- **Klasör Sistemi** — Notlarınızı klasörlere organize edin
- **Kategori Desteği** — Renk kodlu kategorilerle notlarınızı etiketleyin
- **Kopyala & Yapıştır** — Tümünü seç, kopyala, yapıştır tam desteği
- **Arama** — Notlarınızda hızlı arama
- **Sabitleme** — Önemli notları üste sabitleyin
- **Swipe İşlemleri** — Hızlı silme ve sabitleme

## Teknik Detaylar

- **Platform:** iOS 17.0+ (Sadece iPhone)
- **Dil:** Swift + SwiftUI
- **Veri Saklama:** SwiftData
- **Mimari:** MVVM
- **Güvenlik:** LocalAuthentication (Face ID / Touch ID)

## Tasarım

Açık mavi (#A8D8EA) ve su yeşili (#7EC8C8) renk paletine sahip minimalist modern tasarım. SF Symbols ikonları ve smooth animasyonlar ile zenginleştirilmiş kullanıcı deneyimi.

## Kurulum

1. Bu repoyu klonlayın
2. `FCNotes.xcodeproj` dosyasını Xcode ile açın
3. Development team'inizi seçin
4. iPhone 15 Pro simülatör veya gerçek cihazda çalıştırın
